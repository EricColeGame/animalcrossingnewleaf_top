## 電車の旅：みしらぬネコの質問、マップ選び、顔の決定

あなたの旅は、青と白のネコ「みしらぬネコ」の向かいに座る電車の座席から始まります。この何気ない世間話には、後々まで続く重要な意味があります。『とびだせ どうぶつの森』では、みしらぬネコからの最初の質問によって、プレイヤーの恒久的な顔立ち、目の形、初期の表情が決定されます。髪型や目の色、服装は後に商店街のお店で変更できますが、基本的な顔の造形は後から変えることができません。

```
       みしらぬネコの最初の分岐選択
             /                \
        「引っ越し」            「旅行」
            |                     |
      [男の子ルート]        [女の子ルート]
```

プレイヤーコミュニティの報告や攻略データによると、「どうして行くの？」「お金は持ってる？」といった質問への回答ルートによって、男女それぞれ12種類ある固有の顔パターンのうち1つに確定します。

外見の決定と同時に、みしらぬネコからランダムに生成された4つの村のマップが提示されます。一度決定した村の地形は、データを初期化（リセット）しない限り変更できませんので、慎重に吟味しましょう。役場が中央付近にあるか、海岸のスロープ近くにリサイクルショップ「R・パーカーズ」があるか、そして将来の公共事業（PWP）のために十分なまとまった土地があるかを確認してください。川が不自然に村を細分化していたり、スロープがなくマリンスーツを使わないと行けない孤立したプライベートビーチがあったりする地形は避けるのが無難です。

| マップ要素 | 理想的な配置 | 重要な理由 |
| :--- | :--- | :--- |
| **R・パーカーズ（リサ＆カイゾー）** | 海岸のスロープ付近 | 高値で売れる虫や魚を売却する際の移動時間を最小限に抑えられます。 |
| **役場** | 中央または北側の崖付近 | 主要な村の居住スペースを塞がずに、手続きのための移動を短縮できます。 |
| **川の形状** | 緩やかな1本のカーブ | 土地が使いにくい小島状に分断されるのを防ぎ、橋の設置が容易になります。 |
| **海岸へのアクセス** | スロープが2か所ある | 村の海岸線全体を探索するために、いちいちマリンスーツを着る必要がなくなります。 |
| **広場 / シンボルツリー** | 開けた広い区画 | 季節のイベントや特別な行商人が訪れた際に見通しが良くなります。 |

## 1日目の優先事項：村長としての基盤づくり

村に到着すると、どうぶつの住民たちに新村長と勘違いされ、そのまま役場へと案内されます。そこで、あなたの任期を通して右腕としてサポートしてくれる献身的なシーズーの秘書「しずえ」と出会います。

1日目の最優先目標は、自分の家を建てる場所を確保することです。商店街にある「たぬきハウジング」のたぬきちを訪ねて、建設用地を決めましょう。一度家を建てると場所の移動はできないため、景観が良く、周囲にゆとりのある場所を選んで仮住まいのテントを張ります。テントを設置したらたぬきちの元へ戻りましょう。最初の家の建築費として、頭金10,000ベルが必要であると告げられます。

初日の午後にお金を集めるには、自然の恵みを集めるのが一番です。木になっている特産フルーツをすべて収穫し、海岸で貝殻を拾いましょう。これらはまめつぶ商店ではなく、R・パーカーズのリサに売却してください。R・パーカーズのほうが20%高く買い取ってくれます。オープニングセレモニーや住民への挨拶などの詳しい手順については、[IGNによる『とびだせ どうぶつの森』総合ウォークスルー](https://www.ign.com/wikis/animal-crossing-new-leaf/The_First_Day)も参考にしてください。

| 1日目の活動 | 報酬 / 結果 | 優先度 |
| :--- | :--- | :--- |
| **たぬきちとテントを設営** | 永続的な自宅の場所を決定 | 最優先 |
| **広場での記念樹（シンボルツリー）の植樹** | 村長への就任を正式にお祝い | 必須 |
| **スコップとつりざおの購入** | 毎日の資源採取が可能になる | 高 |
| **特産フルーツと貝殻の採集** | 住宅頭金10,000ベルを調達 | 高 |
| **しずえにアドバイスを求める** | 道具、村以外のフルーツ、ジョウロを獲得 | 高 |

役場のカウンターにいるしずえには何度も話しかけてみてください。「暮らしのアドバイス」を選択すると、基本的なチュートリアルが始まります。提示される小さな課題をこなしていくと、つりざおやあみ、村民票の登録要件、そして植えて育てると高値で売れる「村以外のフルーツ（特産品以外の果物）」の山をもらうことができます。

## 役場の機能解放：住民の支持率100%の達成

橋を架けたり、ベンチを設置したり、村の条例を制定したりする前に、村長としての熱意を行動で示し、「住民の支持率100%」を獲得する必要があります。支持率はしずえが管理しており、あなたの村への貢献度を数値化したものです。

支持率を効率よく上げる行動を知らないと、この段階で足踏みしてしまう新米村長も少なくありません。しかし、やるべき仕事を計画的にこなしていけば、初日の午後のうちに達成することが可能です。

| 貢献アクション | 獲得できる支持ポイント | 1日の上限 / 頻度 |
| :--- | :--- | :--- |
| **村メロの変更** | 3ポイント | 1回のみ |
| **村の旗の変更** | 3ポイント | 1回のみ |
| **R・パーカーズでアイテムを売却** | 1回の取引につき1ポイント | 1日の上限あり |
| **村の雑草を抜く** | 雑草1本につき1ポイント | 1日最大16ポイントまで |
| **しおれた花に水をやる** | 花1本につき1ポイント | 1日最大14ポイントまで |
| **掲示板にメッセージを投稿** | 3ポイント | 1回のみ |
| **住民のお願いを叶える** | 1回につき3ポイント | 随時発生 |

支持率が100%に達すると、しずえが祝福してくれ、一晩かけて村長登録の手続きを進めてくれます。翌朝、執務机の後ろにある村長の椅子に座ることで、公共事業の発注や村の条例の制定ができるようになります。

```
       村長の支持率ロードマップ
 [村に到着] -> [テント設営＆10,000ベル支払い]
                           |
       [しずえのチュートリアル・村の仕事を完了]
                           |
           [住民の支持率100%を達成]
                           |
       [翌朝：条例・公共事業が解放]
```

4つの条例により、プレイスタイルに合わせて村の生活リズムを調整できます：

- **美しい村：** 花が枯れなくなり、雑草がほとんど生えず、川や海でゴミが釣れなくなります。初心者や毎日ログインできないプレイヤーに最もおすすめの条例です。
- **朝型の村：** 住民が早く起きるようになり、お店の開店時間が最大3時間早くなります。
- **眠らない村：** お店の閉店時間が最大3時間遅くなり、住民も深夜まで活動するようになります。
- **富豪の村：** お店でのアイテム買取価格が20%上がりますが、販売価格も20%高くなります。

## 財産を築く：ベル稼ぎの戦略と日課

『とびだせ どうぶつの森』でお金を増やすには、毎日のルーティンを確立することが大切です。毎朝午前6:00になると、村の自然環境や隠れたアイテムがリセットされます。

プレイを始めたら、まずはスコップを持ちましょう。村にあるすべての岩を斜め方向から叩いていきます。反動で後ろに下がって連続ヒットが途切れないよう、叩く前にキャラクターの背後に2つの穴を掘っておくのがコツです。1日につき1つの岩から、8回連続で叩くことで最大16,100ベルが飛び出します。また、別の岩のどれか1つは完全に砕け散り、アメジスト、ルビー、きんこうせきなどの貴重な鉱石がドロップします。

さらに毎朝、地面の星形の亀裂の下に4つの化石が埋まっています。博物館のフータに鑑定してもらいましょう。序盤は展示を充実させるために寄贈し、ダブった化石はR・パーカーズで1個あたり1,000〜5,000ベルで売りましょう。

| 日課の資源 | 1日の出現数 | 推定獲得ベル |
| :--- | :--- | :--- |
| **ベルが出る岩（マネーロック）** | 1個 | 16,100ベル |
| **鉱石が出る岩** | 1個 | 2,000〜4,000ベル（きんこうせきは4,000ベル） |
| **化石掘り** | 4か所 | 6,000〜18,000ベル（売却時） |
| **木を揺する（コイン）** | フルーツ以外の木10本 | 合計1,000ベル |
| **木から落ちる家具** | フルーツ以外の木2本 | カタログ用無料アイテム |

この**とびだせ どうぶつの森 初心者ガイド**のルーティンを守っていれば、初期の増築費用はすぐに賄えます。しかし、真の金銭的ターニングポイントは「南の島（コトブキアイランド）」が解放されてから訪れます。

### 最高効率の金策：南の島の高級カブトムシ狩り

2回目の住宅ローンを完済してから数日後、船着き場に前村長のコトブキが現れます。以降、かっぺいの舟に乗って往復1,000ベルで南の島へ行けるようになります。島は常夏であるため、一年中レアな熱帯の甲虫（カブトムシ・クワガタ類）が出現します。

稼ぎを最大化するには、夜の午後7:00以降に島へ行くのがベストです。島の広場にある普通の木、低木、花を取り除き、カナブンやチョウのような安い虫の出現枠を潰してしまいます。外周の砂浜にあるヤシの木・バナナの木だけを残しましょう。

幹に止まる貴重な甲虫を見つけたら、Aボタンを長押ししてあみを構え、すり足でゆっくり近づきます。オウゴンオニクワガタ、ヘラクレスオオカブト、ゴライアスハナムグリなどで島の「お持ち帰り用アイテムカゴ」を満杯にしましょう。40匹の甲虫で満たしたカゴをR・パーカーズで売却すれば、1回で350,000〜450,000ベル以上になり、住宅ローンの悩みはあっという間に消え去ります。

## 公共事業と商店街の発展

村を発展させるには、北側の線路を越えた先にある商店街の拡張も欠かせません。ゲーム開始当初の商店街には、郵便局、たぬきハウジング、博物館、そして小さな「まめつぶ商店」しかありません。商店街の店舗でお金を使うことで店舗がアップグレードされ、新しい住人がお店を開くようになります。

| 店舗 / 拡張施設 | 解放条件 | 主なメリット |
| :--- | :--- | :--- |
| **コンビニまめつぶ** | まめつぶ商店で12,000ベル以上消費＋プレイ日数10日以上 | 営業時間の延長、壁紙・絨毯、パチンコの販売 |
| **シュー シャンク（靴屋）** | エイブルシスターズで8,000ベル以上消費＋プレイ日数10日以上 | 靴、ブーツ、ソックスの購入 |
| **ビューティーサロン スピーディ** | エイブル/シャンクで10,000ベル以上消費＋シャンク解放から7日経過 | 髪型、髪色の変更、カラコン（目の色） |
| **CLUB 444（ししょー）** | コンビニまめつぶへ改築＋住民から6人分の署名を集める | とたけけのライブ（曲入手）、リアクションの習得 |
| **夢見の館** | 村長就任から7日以上＋公共事業を1件以上完成 | 夢を通じて世界中のプレイヤーの村を訪問 |
| **占いの館** | 広場に来たハッケミィに20回占ってもらう | 商店街の常設店舗化、日々の運勢補正 |

村の中に公共事業を建てる際は、場所のバランスをよく考えましょう。村を歩いていると、住民が「ピコン」という効果音とビックリマークを出して駆け寄ってくることがあります。この「ピコン」によって、警察官（おまわりさん）のいる「交番」や「リセット監視センター」といった実用的な施設から、風力発電や枯山水といった装飾品まで、新しい公共事業の提案が行われます。充実した**とびだせ どうぶつの森 初心者ガイド**でもよく言及されるように、「交番」の建設は最優先事項です。クラシックまたはモダンのおまわりさんが落とし物ボックスを管理し、定期的に貴重な無料アイテムを入手できます。

## 毎日のマナーと心得：花、道具、住民との付き合い方

美しい村の景観を維持するには、環境への配慮が必要です。『とびだせ どうぶつの森』では、走り回ることで時間の経過とともに芝生が削れ、人通りの多いルートが獣道（土の露出）になってしまいます。また、花壇の上をダッシュすると花が散ってしまいます。住宅街や花壇の周りを移動するときは、走らずに歩くよう心がけましょう。

道具のアップグレードも早めに進めましょう。まめつぶ商店や博物館のショップを毎日チェックし、通常の道具から銀や金の道具へと更新していきます：

- **銀のスコップ：** 博物館のミュージアムショップで購入可能。叩いたマネーロックからベルの代わりに鉱石が出現することがあります。
- **銀のパチンコ：** 空に2つの銀色の風船が付いて飛んできます。一度に2発の弾を同時に発射できます。
- **金のジョウロ：** 村の環境評価「サイコー」を15日間連続で維持すると、しずえから授与されます。一度に周囲3×3マスの花に水やりができ、枯れた黒いバラに水をやると「金色のバラ」に変化します。

お気に入りの住民には、プレゼントを添えた手紙を送ったり、お願いごとを快く引き受けたり、家に誘われたら遊びに行ったりして仲良くなりましょう。親密度が最大に達すると、村での最高の友情の証である「住民のしゃしん」をプレゼントしてくれます。

## よくある質問（FAQ）

### この『とびだせ どうぶつの森』初心者ガイドで、まず最初に何をすべきですか？
まずはみしらぬネコの質問で好みの顔と地形を選び、便利な場所にテントを張り、役場のしずえに挨拶しましょう。貝殻や特産フルーツを集めてたぬきちへの頭金10,000ベルを支払い、しずえのチュートリアルを進めて基本的な道具を受け取りながら、住民の支持率100%を目指してください。

### 住民が勝手に引っ越してしまうのを防ぐにはどうすればいいですか？
住民は引っ越す前に必ずプレイヤーに知らせてくれます。普段から定期的に話しかけていれば、引っ越しを考えている住民が「ピコン」と駆け寄ってきて予定日を教えてくれます。その際に引き止める選択肢を選べば、引っ越しを取りやめてくれます。長期間ゲームを離れる場合は、住民から引っ越しの相談を受けて引き止めに成功した直後にセーブして終了してください。放置期間中に新たな引っ越しフラグが勝手に進行することはありません。

### 初心者におすすめの村の条例はどれですか？
圧倒的に**「美しい村」**の条例がおすすめです。花が枯れなくなり、村が雑草だらけになるのを防ぎ、水やりや草むしりの負担を大幅に減らせます。毎日必ずログインして水やりをする時間が取れない方でも、自分のペースで安心してスローライフを楽しめます。

### 『とびだせ どうぶつの森』で村以外のフルーツ（特産品以外）はどうやって手に入れますか？
最初の村以外のフルーツは、1日目にしずえの「暮らしのアドバイス」を最後まで進めることで入手できます。さらにマンゴー、ライチ、ドリアン、レモン、ヤシの実、バナナなどの熱帯フルーツは、南の島のミニゲーム（ツアー）中に木から採取できます。ツアー中にポケットへ入れて持ち帰り、自分の村の地面にスコップで植えれば育てることができます。
