『とびだせ どうぶつの森』の花の交配は、ゲーム内でもっともやりがいのある長期プロジェクトのひとつであり、同時にもっとも間違えやすいものでもあります。距離を間違えて植えた2輪の花は、どれだけ欠かさず水をやっても新しい花を生み出すことはありません。しかしルールさえ覚えてしまえば、村は少しずつ黒いバラ、青いスミレ、そして何千ベルもの値がつく金のバラで埋まっていきます。

このガイドでは、『とびだせ どうぶつの森』の花の交配の仕組みを解説します。どの花同士を組み合わせるのか、最高の確率で交配させるにはどう配置するのか、それぞれの交配種にどれだけの価値があるのか、そして「美しい村」条例がどれほど静かに結果を改善してくれるのか。庭に1輪のピンクのチューリップが欲しいだけでも、青いバラの畑を丸ごと作りたい場合でも、手順は同じです。そしてそれは、花に水をやったときゲームが実際に何を判定しているのかを理解することから始まります。

## とびだせ どうぶつの森における花の交配の仕組み

『とびだせ どうぶつの森』の花は四季を通じて育ち、手に入る方法は3つあります。園芸店で買う、住民が植える、あるいは村のあちこちにランダムに芽生える、のいずれかです。同じ種類の花が2輪隣り合って育っていれば、水をやることで翌日に交配種が生まれる可能性があります。

3つの条件がすべて揃う必要があります。ひとつでも欠けると、何も生まれません。

| 条件 | なぜ重要か |
| --- | --- |
| 同じ種類 | バラとチューリップはどれだけ隣に置いても交配しない |
| 直接隣接している | 親となる2輪は接している必要がある — 横並びか斜め |
| 近くに空きマスがある | 新しい花が出現する場所が必要。なければ出現は失われる |

最後の点が、多くの庭が失敗する原因です。プレイヤーはびっしりと美しい花壇を作り、それからなぜ交配種が出ないのか不思議に思います。交配種は親の隣の空いているスペースに出現します。周囲のマスがすべて埋まっていると、ゲームには置き場所がありません。

### 斜め植えがもっとも効率的な配置である理由

コミュニティの報告は、斜め配置が最良のセットアップであると一貫して指摘しています。2輪を斜めに置き、反対側の斜めのマスを空けておきます。これにより、そのペアには1つではなく2つの有効な出現ポイントが生まれ、直線配置と比べて1晩あたりの確率がおよそ2倍になります。

| 配置 | セットアップ方法 | 向いている用途 |
| --- | --- | --- |
| 斜めペア | 2輪を斜めに置き、反対側の角を空ける | ペアあたりの交配確率が最大 |
| チェッカー柄 | 花と空きマスを交互に並べる | 毎朝の新しい出現を見つけやすい |
| 長い列 | 花を一直線に並べ、毎日水やり | スペースを埋めること。交配の最大化には不向き |
| 隔離ペア | 各ペアを他からフェンスで区切る | どの組み合わせが何を生んだか記録できる |

複数の種類を同時に交配させているなら、各ペアを隔離しましょう。そうしないと、あの思いがけない紫のパンジーをどの親が生んだのか永遠にわからず、再現することもできません。

## すべての花の種類と交配カラー

『とびだせ どうぶつの森』には6種類の一般的な花があり、それに加えて特別扱いのカーネーションがあります。全種類に共通する自然な色は赤、黄、白です。それ以外はすべて交配種です。

| 種類 | 自然な色 | 交配カラー |
| --- | --- | --- |
| バラ | 赤、黄、白 | ピンク、オレンジ、紫、黒、青、金 |
| チューリップ | 赤、黄、白 | ピンク、オレンジ、紫、黒 |
| コスモス | 赤、黄、白 | ピンク、オレンジ、黒 |
| パンジー | 赤、黄、白 | オレンジ、紫、青 |
| スミレ | 黄、白、紫 | 青 |
| ユリ | 赤、黄、白 | ピンク、オレンジ、黒 |
| カーネーション | 赤、ピンク | 白 |

知っておくと役立つ小さな点がひとつ。チューリップは虫を引き寄せません。テントウムシ、チョウ、カマキリ、カタツムリを探しているなら、庭には代わりにバラ、コスモス、パンジー、スミレ、ユリを植えましょう。花はアクセサリーとして身につけることもでき、貴重な交配種を地面に置いて危険にさらすことなく自慢できる良い方法です。

## 特別な花、カーネーション、村の条例

6種類の標準的な花以外にも、いくつかの特別な植物は異なる挙動をし、計画に組み込む価値があります。

| 特別な植物 | 入手方法 | 備考 |
| --- | --- | --- |
| ピンクと赤のカーネーション | 母の日と父の日に郵便で届く | 店では買えない |
| 白いカーネーション | 赤 + ピンク、またはピンク + ピンクから交配 | 唯一交配で作るカーネーション |
| スズラン | 村が最高の環境状態になると出現 | 交配しない。金のじょうろだけが復活させる |
| 四つ葉のクローバー | 普通のクローバーからまれに拾える | ハッピーホームアカデミーのスコアに7,777ポイント |
| ラフレシア | 村に雑草がたまると育つ | ハエを引き寄せる。雑草を取り除くと枯れて死ぬ |
| タンポポ | 3月から10月まで野生で育つ | 摘まずに放っておくとタンポポの綿毛になる |

「美しい村」条例は、交配をする人にとって最大の生活の質の向上です。これを制定すると、住民がはるかに頻繁に花に水をやり、植え、交配種が出現する確率がおよそ20%高くなります。さらに花が枯れなくなるので、ゲームを離れた1日で庭を失うことがなくなります。村づくりやシリーズ全体については、任天堂公式のどうぶつの森サイトでさらに詳しく読むことができます。

### 実際に交配種を生み出す毎日のルーティン

| タスク | なぜ重要か |
| --- | --- |
| すべての親ペアに水をやる | 水をやっていない花は交配せず、枯れることもある |
| 毎朝、出現を確認する | 新しい交配種は一晩で現れる |
| 新しい交配種を育苗エリアに移す | マスが空き、親が再び出現させられる |
| 生産を止めたペアは植え直す | 単にハズレの組み合わせもある |
| 予備のじょうろを収納に置く | 途中で切らすと1日無駄になる |

もっともよくある間違いは、交配種が出現した場所にそのままにしておくことです。親の隣に陣取った新しい花は、ペアが再び生産するために必要なマスをふさいでしまいます。掘り起こして移せば、その場所は再び生産的になります。これを徹底しているプレイヤーは、新しい花を眺めてそのままにする人よりはるかに良い結果を報告しています。

## よくある質問

**『とびだせ どうぶつの森』の花の交配が機能するには、両方の花に水をやる必要がありますか？**
はい。一晩で交配種が出現する可能性を得るには、同じ日に両方の親に水をやる必要があります。ペアの片側だけに水をやっても何も起こりません。

**異なる2種類の花で交配種はできますか？**
いいえ。交配種は同じ種類の2輪の間でのみ生まれます。バラはバラと、パンジーはパンジーと交配し、種類をまたぐ組み合わせは何も生みません。

**交配種が出現するまでどれくらいかかりますか？**
決まった日数はありません。1〜2晩で交配種を生むペアもあれば、何週間もかかるものもあります。だからこそ、成功する『とびだせ どうぶつの森』の花の交配は、1つのペアを待つのではなく、多くのペアを同時に回すことが大切なのです。

**花の交配に「美しい村」条例は価値がありますか？**
ほとんどのプレイヤーにとっては、はい。住民がより頻繁に水をやり植え、交配種が出現する確率はおよそ20%高くなり、花は完全に枯れなくなります。庭づくりが主なプロジェクトなら、ゲーム内で最高の条例です。

**青いバラへの最短ルートは何ですか？**
紫のバラとオレンジのバラを交配し、その2輪に水をやり続け、斜めに植えておきます。青いバラは一般的な交配種のなかでもっとも出現が遅いので、紫とオレンジのペアを何組も並べて回し、それぞれに空きマスを確保してあげましょう。
