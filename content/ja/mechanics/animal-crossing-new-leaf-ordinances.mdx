## とびだせ どうぶつの森の条例とは？

村長になれることは、New Leafがどうぶつの森シリーズにもたらした最大の変化であり、条例はその権限を最も端的に示す仕組みです。とびだせ どうぶつの森の条例とは、役場で成立させる村全体の方針で、店がいつ開くか、雑草がどれくらいの速さで増えるか、サメを売ったときにいくらベルが手に入るかといった村のルールを恒久的に変えてしまいます。

同時に有効にできるのはひとつだけで、どの条例も成立に20,000ベルかかります。序盤ではかなりの出費になるので、カウンターに向かう前に4つの選択肢すべてを理解しておく価値があります。

選択を間違えなければ、ゲームはあなたの現実の生活リズムに静かに合わせてくれます。間違えれば、何週間も自分の村と戦うことになります。必要な情報をすべてまとめました。

| 条例 | 主な効果 | 向いている人 |
|---|---|---|
| 美しい村条例 | 花が枯れない、雑草が減る、水にゴミが浮かない、ゴキブリが出ない | 忙しいプレイヤーと園芸好き |
| 朝型条例 | 店の開店・閉店が3時間早くなる、住民が早起きになる | 朝に遊ぶプレイヤー |
| 夜型条例 | 店の開店・閉店が3時間遅くなる、住民が夜更かしになる | 夕方・夜に遊ぶプレイヤー |
| 稼ぎ時条例 | 店の買値・売値がどちらも約20%上がる | ベル稼ぎをしているプレイヤー |

## 4つの条例をすべて解説

それぞれの方針は異なる問題を解決します。以下では、ゲーム内での挙動と長年にわたるコミュニティの報告に基づき、実際に何が起こるのかを説明します。

### 美しい村条例

これはメンテナンス不要の選択肢です。花はまったく枯れなくなるので、水やりをする必要がなくなります。交配花を作ったり、花壇で村を飾ったりしている人にとっては大きな快適さの向上です。雑草の発生率は目に見えて下がり、川や海にゴミが浮かばなくなり、家にゴキブリも出なくなります。

根強い誤解をひとつ解いておきましょう。美しい村条例は住民の引っ越しを**止めません**。影響するのは環境だけです。毎日の手入れなしで整った村を保ちたいなら、これがおすすめです。

### 朝型条例

朝型条例は村全体を3時間前倒しにします。店は3時間早く開き、3時間早く閉まり、住民もずっと早い時間から起きて歩き回ります。

仕事や学校の前に遊ぶ人なら、無駄だった時間が生産的な時間に変わります。一日が始まる前に店に寄り、カブの価格を確認し、朝だけ出現する虫や魚を捕まえられます。夜型の人にとっては厳しい代償で、閉店時間がいつもより3時間早くやってきます。

### 夜型条例

朝型条例のちょうど裏返しです。店は3時間遅く開き、3時間遅くまで開いており、住民も夕方遅くまで活動しています。コミュニティの報告では、夕食後にしか遊べないプレイヤーの間で最も人気の選択肢として一貫して挙げられています。

22時に村を起動してすべての店が閉まっていた経験があるなら、夜型条例が解決策です。ただし、朝のプレイは買い物にはほぼ使えなくなることを覚えておきましょう。

### 稼ぎ時条例

稼ぎ時条例は両方向の価格を上げます。店では約20%多く支払い、売るときは約20%多く受け取れます。お金が湧いてくるわけではなく、すでに行っていることを増幅するだけです。

売る量が買う量より多ければ純粋な強化です。買う量が売る量より多ければ、静かに財布が削られていきます。住宅ローンを積極的に返済している人や、大きな公共事業のために貯金している人向けの条例です。

| 条例 | メリット | デメリット |
|---|---|---|
| 美しい村条例 | 水やりの手間ゼロ、雑草が減る、水がきれい、ゴキブリが出ない | 店の営業時間やベルの価格には効果なし |
| 朝型条例 | 店と住民が3時間早く活動する | 店も3時間早く閉まる |
| 夜型条例 | 店と住民が3時間遅くまで活動する | 店も3時間遅く開く |
| 稼ぎ時条例 | 売ったものすべてで約20%多くベルが手に入る | 店で買うものすべてが約20%高くなる |

## 役場で条例を成立させる方法

村の方針を変えるのに1分もかかりませんが、実行できるプレイヤーがひとりだけなので、新しい村長は手順でつまずきます。

| ステップ | やること |
|---|---|
| 1 | 村長としてプレイする——村で最初に作ったプレイヤーキャラクター |
| 2 | 営業時間内に役場に入る |
| 3 | カウンターのしずえに話しかける |
| 4 | メニューから条例の項目を選ぶ |
| 5 | 希望する条例を選んで確定する |
| 6 | 20,000ベルの費用を支払う |
| 7 | 効果が出るまで次のゲーム内の日を待つ |

いくつか重要なルールがあります。条例は重複できません。新しいものを成立させると、古いものは即座に置き換わります。村に住む他の人間プレイヤーは方針を変えられず、その権限は村長だけが持ちます。すでに条例が有効かどうかわからないときは、しずえに聞けば教えてくれます。

## 費用・タイミング・その他のルール

条例は一度きりの買い物ではなく、繰り返しかかる投資です。方針を切り替えるたびに費用を再び支払います。多くの村長はこれを季節ごとの判断として扱っています。忙しい時期は夜型条例、生活が慌ただしくなったら美しい村条例、といった具合です。

| 項目 | ルール |
|---|---|
| 成立にかかる費用 | 20,000ベル |
| 変更にかかる費用 | 毎回20,000ベル |
| 同時に有効な数 | ひとつ |
| 効果が出るタイミング | 次のゲーム内の日 |
| 成立できる人 | 村長のみ |
| 場所 | 役場のカウンター |
| 取り消し可能？ | 可能——別の条例を成立させるだけ |

もうひとつ考慮点があります。一部のサービスは独自のスケジュールで動いており、店の営業時間のシフトに完全には従いません。特にRe-Tailは、どの条例を選んでも長い毎日の営業時間を保つと、プレイヤーの経験から報告されています。博物館、島、その他の特別な施設も村の方針とは独立して運営されています。

## どの条例を選ぶべき？

条例は、こう遊びたいという理想ではなく、実際の遊び方に合わせましょう。下の表が最も早く判断できる方法です。

| あなたが… | 選ぶべきもの |
|---|---|
| 仕事や学校の前に遊ぶ | 朝型条例 |
| 夜遅くに遊ぶ | 夜型条例 |
| 気ままな時間に遊び、花の水やりを忘れる | 美しい村条例 |
| 住宅ローンや橋のためにベルを稼いでいる | 稼ぎ時条例 |
| 交配花を作っている | 美しい村条例 |
| 理想の村の評価を目指している | 美しい村条例 |
| 店で家具や服をほとんど買わない | 稼ぎ時条例 |

多くの村長が使っている実践的な戦略は、ローンがまだ大きく村が未整備なうちは**稼ぎ時条例**で始めるというものです。ローンを返し終えて村を飾り終えたら、**美しい村条例**に切り替えて日々の手入れをなくします。時間が限られているプレイヤーはどちらも飛ばして、自分の自由時間に合う店の営業時間の条例を選ぶことが多いです。

任天堂が運営する[どうぶつの森シリーズ公式サイト](https://animal-crossing.com/)はシリーズ全体の参考になりますが、New Leaf固有の仕様は役場でゲーム内で確認するのが一番確実です。

### 後悔しないための簡単なヒント

- **大きな買い物の前に稼ぎ時条例を成立させない。** 家具一式や苗木のまとめ買いは明らかに高くつきます。
- **「設定して忘れる」なら美しい村条例が最強。** メリットを足すのではなく、手間をなくしてくれます。
- **切り替えは自由。** 費用は一律20,000ベルなので、後から気が変わっても十分に手が届きます。
- **切り替え後は店の営業時間を確認。** 3時間のズレは最初の数日、油断している人を驚かせます。
- **朝型と夜型は併用できない。** 両方は持てないので、より大事な半日を選びましょう。
- **島は独自の時計で動く。** 条例を変えてもTortimer Islandのスケジュールには影響しません。

## よくある質問

**とびだせ どうぶつの森で複数の条例を同時に有効にできますか？**

いいえ。村で同時に有効にできる条例はひとつだけです。新しい条例を成立させると前の方針は自動的に置き換わり、変更のために20,000ベルを再度支払います。

**New Leafで条例を変更するのにいくらかかりますか？**

成立も変更も毎回20,000ベルで、役場のカウンターでしずえに支払います。以前使った条例に戻す場合でも割引はありません。

**美しい村条例は住民の引っ越しを止めますか？**

いいえ、これはよくある誤解です。美しい村条例は花が枯れるのを防ぎ、雑草を減らし、水のゴミを取り除き、ゴキブリの発生を止めます。住民の引っ越しは別の友好度とタイミングの仕組みで決まります。

**条例が効果を発揮するまでどのくらいかかりますか？**

新しい方針は次のゲーム内の日から始まります。今日条例を成立させれば、店の営業時間などの効果は明日反映されます。

**条例は島や博物館に影響しますか？**

基本的にいいえ。Tortimer Islandやいくつかの特別な施設は独自のスケジュールを保っています。朝型・夜型条例による3時間の店のシフトは、コミュニティの報告によれば、主にメインストリート周辺の店に適用されます。
