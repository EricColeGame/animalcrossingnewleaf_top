## 『とびだせ どうぶつの森』でカブ市場が今も重要な理由

カブ市場の勝敗は日曜の昼前に決まる。**『とびだせ どうぶつの森』のカブ**は、このゲーム唯一の本格的な投資要素だ。歩き回るイノシシから安く買い、R・パーカーズのアルパカに高く売り、数字が噛み合うことを祈る。うまくいけば、たった1週間で家の増築費用を丸ごと稼げる。失敗すれば、ハエがたかる腐った野菜をポケットに抱えて終わる。

そのリスクこそ、**『とびだせ どうぶつの森』のカブ**が発売から何年も経った今なお、最も語られるシステムのひとつであり続ける理由だ。虫取りや釣りと違い、カブは計画性、記録、そして少しの度胸に報いてくれる。このガイドでは、購入、価格追跡、売却、保管、取引という一連の流れを順に解説するので、当て推量はやめて利益を出せるようになろう。

お店、村での暮らし、日々のルーティンがどう噛み合うのか、まず全体像をつかみたいなら、任天堂の[『とびだせ どうぶつの森』公式ページ](https://www.animal-crossing.com/newleaf/)が、表計算とにらめっこする前の確かな出発点になる。

## 『とびだせ どうぶつの森』でカブ市場はどう機能するか

基本の流れは単純だ。村を歩き回るイノシシのカブリバが、日曜の朝にカブを売っている。そのカブをR・パーカーズへ運び、リサが1日2回変動する価格で買い取る。買値とリサの提示額の差が、そのまま利益率になる。

それ以外の要素 — 価格パターン、高騰、腐敗タイマー — は、すべてその差を予測不能にするために存在している。

**カブの基本をひと目で**

| 項目 | 仕組み |
|---|---|
| 売る人 | 村を歩き回るイノシシ、カブリバ |
| 出現時間 | 日曜の朝、おおよそ6:00〜12:00 |
| 買える単位 | カブ10個の束。1束につき持ち物欄1マス |
| 一般的な売値 | カブ1個あたり約90〜110ベル（コミュニティ追跡の範囲） |
| 買い取る人 | R・パーカーズのリサ。他の店では受け取ってもらえない |
| 価格更新 | 1日2回：午前に1回、正午過ぎに1回 |
| 絶対的な期限 | 翌週日曜の6:00までに売る |

初心者がつまずくポイントが2つある。1つ目は、リサの価格はカブ1個あたりなので、10個の束を売ると掲示板の数字の10倍が支払われる。2つ目は、正午前に見た価格は正午を過ぎた瞬間に永遠に消えるという点だ。取っておく方法はない。

## カブリバから買う：日曜の朝のルーティン

カブリバはじっとしていない。村中を歩き回るので、運が悪いと彼女を探すだけで10分かかることもある。6:00を過ぎたらすぐに探索を始め、まず広場、海岸のスロープ、駅周辺の道を確認しよう。

彼女は10個単位でしか売らず、値引き交渉にも応じない。提示価格はその朝のあいだ固定なので、いったん離れて戻ってきても意味はない。自分でコントロールできるのは準備だ。

**日曜の朝のチェックリスト**

| 手順 | やること | 重要な理由 |
|---|---|---|
| 1 | 前夜にベルをおろしておく | ツケは効かないうえ、朝の用事は時間を食う |
| 2 | 持ち物欄を5〜10マス空ける | 10個の束ごとに1マス使う |
| 3 | 6時以降に村全体を探索する | カブリバは歩き回るので見逃しやすい |
| 4 | 10個単位で買う | 彼女が売る唯一の単位 |
| 5 | 平均購入単価を書き留める | 価格を判断するには基準が必要 |

多くのプレイヤーが使っている実践的な予算ルールは、1週間の仕入れに貯金の半分以上を使わないことだ。大きな高騰が来なくても、道具や家具、公共事業に使うベルは残しておける。

## R・パーカーズの価格を読む：4つのパターン

リサはカブ価格を1日2回更新する。プレイヤーの経験と長年のコミュニティ追跡によると、各村は週ごとに4つの大きな価格パターンのどれかに振り分けられる。どれに当たっているかを知れば、売るタイミングの判断がまったく変わる。

**4つの価格パターン**

| パターン | 典型的な形 | 最善の行動 |
|---|---|---|
| 下降型 | 週を通して下がり続ける | 早めに売るか、小さな損を受け入れる |
| 変動型 | ランダムな上下、大きな波はまれ | 納得できる利益が出たら売る |
| 小さな高騰 | 徐々に上がって200台前半に達する | ピークまで持ち、そこで全部売る |
| 大きな高騰 | 急上昇し、500ベルを超えることもある | 見つけた瞬間に売る |

上記の数字は、長年にわたってプレイヤーから最もよく報告されてきた範囲を反映している。村の数値は毎週新しく決まるので、地図ではなく方位磁針として扱おう。

利益を出すプレイヤーとイライラするプレイヤーを分ける習慣がいくつかある。

- **毎日2回チェックする。** 午前と午後の価格は別々に決まるので、片方を飛ばすとピークを逃すことがある。
- **数値をメモや表計算に記録する。** 履歴が残っていれば、上昇中か下降中かが一目でわかる。
- **損益分岐点を把握する。** カブリバに100ベルで買い、リサが140ベルを提示したら40%の利益だ。80ベルなら20%の損で、おそらくさらに悪化する。
- **すでに起きた高騰を追いかけない。** 価格は正午にリセットされる。昨日の480ベルは戻ってこない。

## 腐敗、保管、タイムトラベルのルール

カブは腐る。この一点が、ゲーム内のどの要素よりも多くの不安を生む。だからこそ正確に理解しておく価値がある。

カブは買った翌週の日曜6:00、つまりカブリバが村に戻ってきた瞬間に腐る。その時点で手元に残っているカブはすべて腐ったカブになり、二束三文でしか売れず、食べることもできない。

**腐敗ルールをひと目で**

| 状況 | どうなるか |
|---|---|
| 日曜6:00を過ぎてもカブを持っている | 腐る |
| 1日でも過去へタイムトラベルする | 即座に腐る |
| 日曜を越えて未来へタイムトラベルする | 腐る |
| 屋外の地面に落とす | それでも腐る。しかも放置物は村の評価を下げる |
| 家やロッカーに保管する | 正確なタイミングについてコミュニティの報告は分かれるため、日曜を絶対の期限として扱う |

最後の行は強調に値する。保管中のカブが持ち歩いているカブと同じ瞬間に腐るかどうかは、プレイヤーの経験でも意見が分かれている。だから最も安全な方針は単純だ。日曜の朝にカブをまだ所有していない状態にしておくこと。

コンプリートを目指す人にとっての小さな救いは、地面に置いた腐ったカブがアリを引き寄せることだ。虫図鑑を埋めているなら、アリを捕まえる最も簡単な方法のひとつになる。

## 他の村とのカブ取引

ここからが、カブを社会的なイベントに変えた部分だ。村ごとに価格が決まるため、友達のR・パーカーズが自分の村の3倍で買い取っていることもある。売るために他の村を訪れることは、『とびだせ どうぶつの森』を代表するマルチプレイの儀式のひとつになった。

コミュニティは絶えずこれを中心に動いてきた。掲示板のスレッド、カブ専門のsubreddit、Tumblrブログには、午後の価格を投稿し、見知らぬ人に門を開くホストであふれた。利益の一部を求める人もいれば、レア家具を求める人もいて、ただ訪問者を欲しがる人もいた。

**カブ訪問のエチケット**

| エチケット | 重要な理由 |
|---|---|
| 勝手に歩き回る前に確認する | ホストは交配花の近くに知らない人が来ると不安になる |
| 道から外れない | 多くの村はしっかり整備されている |
| ホストが求めたらチップを置く | 取引コミュニティを健全に保つ |
| 許可なく買い物や穴掘りをしない | そこは相手の村であり、自由勝手な場所ではない |
| 売ったら礼を言って退出する | 長居すると、入るのを待っている他の売り手を妨げる |

ホストなら、価格を投稿し、明確なルールを設定し、人が集まることを想定しておこう。訪問者なら、ポケットを空にし、チップを用意して訪れよう。築いた善意は、次に500ベルで買ってくれる相手が必要になったときに役立つ。

## よくある質問

**『とびだせ どうぶつの森』でカブリバはいつカブを売りますか？**

カブリバは毎週日曜の朝、おおよそ6:00から12:00のあいだに村へ現れ、一箇所に留まらず歩き回る。彼女を逃すと、次の機会まで丸一週間待つことになる。

**カブは腐るまでどれくらい持ちますか？**

買った翌週の日曜6:00に腐る。過去へタイムトラベルすると即座に腐り、日曜を越えて未来へ飛んでも同じだ。6日以内に売るつもりで計画しよう。

**カブの最高価格はいくらですか？**

コミュニティの追跡では、カブ1個あたり500ベルを超え、時には600ベルに近づく大きな高騰も報告されている。ほとんどの週はそれよりずっと低いので、1日2回のチェックがこれほど重要なのだ。

**カブはどこで売りますか？別の店でも売れますか？**

買い取ってくれるのはR・パーカーズのリサだけだ。彼女は正午前と正午過ぎで違う価格を提示し、腐ったカブは受け取らない。腐ったカブはごくわずかな金額にしかならない。

**腐ったカブはどうすればいいですか？**

1つを屋外の地面に置けばアリが集まってくるので、虫集めには便利だ。それ以外は、リサの提示額で残りを売り、来週の仕入れのためにスペースを空けよう。
