## なぜ『とびだせ どうぶつの森』のamiibo住民が今も重要なのか

ゲームの長い歴史の大半において、特定の住民を手に入れるもっとも簡単な方法は、オンラインで他のプレイヤーと交換するか、ランダムなキャンプ場が良い住人を連れてくるのを祈ることでした。それが2度変わりました。1度目はamiibo+アップデートが登場したとき、2度目は2024年4月に任天堂が3DSのオンラインサービスを終了したときです。インターネットを介した交換はなくなりました。しかしamiiboのスキャンは残っています。これは完全にローカルな機能で、オフラインでも永遠に動作します。

そのため、フィギュアとカードは、隣人を選ぶ唯一の確実な方法となっています。運も、夢番地を持っている友達も、より良いメンバーを求めて村をリセットする必要もありません。

| 方法 | 現在も使える？ | どの程度選べる？ |
|---|---|---|
| amiiboフィギュアとカード | はい | 正確に住民を選べる |
| ランダムなキャンプ場訪問者 | はい | なし — 来た人次第 |
| ローカル通信交換 | はい | 高いが、近くにプレイヤーが必要 |
| オンライン交換と訪問 | いいえ（2024年4月終了） | もう利用不可 |

長い休みの後にゲームへ戻ってきた人にとって、この表がすべてを物語っています。オンラインの近道は消え、プラスチックの近道だけが残ったのです。

## amiibo+アップデートの仕組み

amiibo機能は、『とびだせ どうぶつの森』の発売当初は含まれていませんでした。2016年11月2日に配信された無料アップデートで追加され、同時にオートキャンプ場、キャンピングカーの内装、MEOWクーポンと呼ばれる新しい通貨も導入されました。もしあなたのゲームが一度も更新されていないなら、スキャン機能は一切反応しません。フィギュアをリーダーにタッチしても、何も起こりません。

何かをスキャンする前に、まず自分のハードウェアがamiiboを読み取れるか確認しましょう。新しい本体にはリーダーが内蔵されていますが、古い本体には任天堂が別売りしていたアクセサリが必要です。

| 本体 | NFC内蔵？ | スキャンに必要なもの |
|---|---|---|
| Newニンテンドー3DS / Newニンテンドー3DS LL | はい | 追加なし |
| Newニンテンドー2DS LL | はい | 追加なし |
| ニンテンドー3DS / ニンテンドー3DS LL | いいえ | ニンテンドー3DS NFCリーダー/ライター |
| ニンテンドー2DS | いいえ | ニンテンドー3DS NFCリーダー/ライター |

ハードウェアの準備ができたら、手順は短く、いつも同じです。

| 手順 | やること |
|---|---|
| 1 | amiibo+アップデートをダウンロードする。ニンテンドーeショップでは新しいゲームは販売されなくなりましたが、ソフトウェア更新は引き続きダウンロードできます。 |
| 2 | NFCの設定を確認する — 内蔵か、リーダーアクセサリか。 |
| 3 | 村の北にあるオートキャンプ場へ行く。 |
| 4 | キャンプ場のamiiboリーダーを操作し、フィギュアまたはカードをタッチする。 |
| 5 | キャンピングカーに入り、キャンパーと話して引っ越しを頼む。 |

キャンパーが承諾するのは、村に空きがある場合だけです。すでに10人の住民が住んでいるなら、誰か一人に引っ越してもらう必要があります。公式のフィギュア対応については、[Nintendoのamiiboハブ](https://www.nintendo.com/us/amiibo/)で詳しく確認できます。

## 招待できるamiibo限定住民の全員

『とびだせ どうぶつの森』には、amiiboを通してのみ存在する住民が8人います。4人は『ゼルダの伝説』から、3人はSplatoon風、1人はモンスターハンターのクロスオーバーです。彼らは通常のキャンプ場訪問では決して現れないため、スキャンが唯一の入手方法です。

| 住民 | テーマ | 呼び出すamiibo |
|---|---|---|
| エポナ | ゼルダ | リンク（ムジュラの仮面、時のオカリナ、ライダー）、シーク |
| ガノン | ゼルダ | ボコブリン、ガノンドロフ、ガーディアン、8ビットリンク |
| メドリ | ゼルダ | トゥーンリンクとその他のゼルダフィギュアのほとんど |
| ウルフリンク | ゼルダ | ほとんどのリンクフィギュア、ゼルダ（大乱闘スマッシュブラザーズ） |
| アオリ | Splatoon（Callie風） | アオリ |
| ホタル | Splatoon（Marie風） | ホタル |
| インクリング | Splatoon | Splatoonまたはスマブラシリーズのインクリングフィギュア |
| アイルー | モンスターハンター | ナビルー、ベリオロス、アユリア |

ゼルダのフィギュアが4人の異なるキャンパーに分かれていることに注目してください。ムジュラの仮面、時のオカリナ、ライダーシリーズのリンクのamiiboはすべてエポナを連れてきますが、一般的なリンクのフィギュアは通常ウルフリンクを連れてきます。特定のキャンパーを狙っているなら、買う前にこの表を確認しましょう。エポナとウルフリンクの違いは、どのリンクをタッチするかだけであることが多いのです。

これらのキャンパーは全員、他では手に入らない家具が積まれたテーマ別のキャンピングカーと一緒にやって来ます。その家具はベルではなくMEOWクーポンで購入するため、誰かを招待する前にクーポンを貯めておく価値があります。

## どのカードとフィギュアが使えるか

フィギュアばかり注目されますが、『どうぶつの森』のamiiboカードシリーズが大部分の仕事を担っています。カードはいくつかのグループに分かれており、それぞれキャンプ場での動作が異なります。

| amiiboの種類 | キャンピングカー訪問？ | 引っ越し可能？ | 得られるもの |
|---|---|---|---|
| amiibo+シリーズのカード（サンリオコラボ含む） | はい | はい | キャンピングカー訪問、テーマ家具、完全な引っ越し |
| 第1弾～第4弾とプロモの非SPカード | いいえ | はい | ゆうたろうがアイテムをくれるか、引っ越しを手配 |
| SPカード（あやしいねこ、フータンなど） | いいえ | いいえ | 特別なアイテム1つ |
| フータンとフーコのフィギュア | はい | いいえ | キャンプ場訪問または贈り物アイテム |
| むらびと（大乱闘スマッシュブラザーズシリーズ） | いいえ | いいえ | ゆうたろうを呼び出す |

パターンは単純です。カードがamiibo+シリーズに属していれば、キャンピングカーと新しい隣人を期待しましょう。古いカードなら、代わりにゆうたろうが現れます。彼は以前のシリーズのスキャンを担当する精霊で、贈り物か新しい住民かを選ばせてくれます。

### 訪問するだけで決して引っ越さない特別なキャラクター

ゲームでもっとも愛されているキャラクターの何人かは、喜んで現れますが、荷ほどきを拒みます。フータンとフーコは『どうぶつの森』のフィギュアで呼び出せ、どちらもキャンプ場を訪れたりアイテムを渡したりしますが、住民になることはできません。同じことが、大乱闘スマッシュブラザーズのむらびとのフィギュアをタッチすると現れるゆうたろうや、特別なアイテムしか生み出さないあやしいねこのようなSPカードにも当てはまります。引っ越し目的で集めているなら、これらはメンバー追加ではなく嬉しいおまけです。

## 欲しいamiibo住民を迎えるためのコツ

スキャンは寛容ですが、いくつかの習慣が時間とお金を大幅に節約します。

| コツ | 役立つ理由 |
|---|---|
| 空き地を少なくとも1つ確保する | 村にすでに10人の住民がいると、amiiboキャンパーは引っ越せません。 |
| スキャン前にセーブする | 間違ったフィギュアをタッチしたら、セーブせずに終了してやり直せます。 |
| フィギュアと住民を一致させる | ゼルダのamiiboは4人の異なるキャンパーに対応するので、買う前に確認しましょう。 |
| パックではなく単品カードを買う | 特定の隣人だけが欲しいときは安く済みます。 |
| NFCリーダーを早めに用意する | 古い3DSや2DS本体は、リーダーなしではスキャンに使えません。 |
| MEOWクーポンを貯める | キャンピングカーの家具はクーポン専用で、いくつか欲しくなるでしょう。 |

もう一つ知っておく価値があるのは、コミュニティの報告によると、amiiboキャンパーは引っ越した後、普通の住民とまったく同じように行動するということです。手紙を送り、頼み事をし、やがて他の住民と同じように引っ越したいと言い出します。フィギュアをスキャンすれば彼らは家に入りますが、引き留めるかどうかはあなた次第です。

## よくある質問

**『とびだせ どうぶつの森』のamiibo住民を使うにはamiibo+アップデートが必要ですか？**

はい。未更新のゲームではスキャンしても何も起こりません。アップデートは無料で、今もダウンロード可能です。これによりオートキャンプ場、キャンピングカーの内装、MEOWクーポンが追加されます。

**初代3DSや2DSでamiiboをスキャンできますか？**

できますが、直接はできません。これらのモデルにはNFCリーダーが内蔵されていないため、ニンテンドー3DS NFCリーダー/ライターのアクセサリが必要です。Newニンテンドー3DS、Newニンテンドー3DS LL、Newニンテンドー2DS LLは、箱から出してすぐにフィギュアやカードをスキャンできます。

**どのamiiboが最も多くの住民を解放しますか？**

Splatoonシリーズがもっとも効率的です。インクリングのフィギュアはどれでも、住民のインクリングを呼び出せます。アオリとホタルのフィギュアはそれぞれアオリとホタルを解放します。ゼルダのフィギュアは逆で、4人の異なるキャンパーに分かれているため、1体のリンクではセット全体をカバーできません。

**amiibo住民は後で引っ越せますか？**

できます。一度落ち着くと、amiiboキャンパーは他の住民と同じ日常を送り、やがては引っ越したいと言い出します。永久に住んでほしいなら、その頼みを断るか、後で彼らのamiiboを再度スキャンして呼び戻しましょう。

**サンリオカードは本物のamiiboですか？**

はい。サンリオコラボカードはamiibo+カードシリーズの一部として発売されたため、そのセットの他のカードと同じようにスキャンできます。キャンピングカー訪問、テーマ家具、そして村に引っ越せる住民が手に入ります。
