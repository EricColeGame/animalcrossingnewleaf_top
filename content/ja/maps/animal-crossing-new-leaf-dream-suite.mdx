## とびだせ どうぶつの森の夢見の館とは？

夢見の館 — 古いコミュニティ投稿では「Dream Mansion」と呼ばれることもある — は、商店街にある建物だ。ゆめみが切り盛りしており、玄関で出迎え、2つのサービスを提供している：あなたの町を夢としてアップロードするか、他の誰かの夢へと送り出すかだ。

夢とは、凍結されたスナップショットだ。あなたの花、道、家のレイアウト、住民の配置は、アップロードした瞬間のままに表示される。訪問者は歩き回り、住民と話し、あなたのデザインの選択を研究できるが、アイテムをポケットに入れたり、何かを永久に変更したりすることはできない。あなたの町が危険にさらされることは決してない。

| 特徴 | 詳細 |
|---|---|
| 場所 | 商店街、公共事業として建設 |
| 受付 | ゆめみ。すべての夢のサービスを説明し、操作する |
| 別名 | Dream Mansion（古いガイドやファンウィキ） |
| 主な機能 | 自分の町をアップロード、他の町を夢として訪問 |
| 建設費用 | 234,000ベル |
| 夢を訪問する費用 | 無料 |
| 夢をアップロードまたは更新する費用 | 1回につき5,000ベル |

この建物はあなたの町ではなく商店街にあるため、貴重な土地を消費しない。道や果樹園、公共事業のためにすべての土地を保持できる。

## 夢見の館の解放方法は？

夢見の館は、初日からふらりと入れる店ではない。公共事業であり、商店街に現れる前に自分で費用を支払う必要がある。234,000ベルと、ゲーム内でもかなり高額なプロジェクトの一つだ。

任天堂は、このプロジェクトがリストに現れる明確なトリガーを公表しておらず、プレイヤーの経験も様々だ。コミュニティの報告では、よく整備された町 — 住宅ローンを返済し、いくつかの以前のプロジェクトを完了し、かなりのプレイ時間を費やしている — ことが提案が現れる条件だと示唆されている。

| ステップ | やること | 重要な理由 |
|---|---|---|
| 1 | 町を発展させ、住宅ローンを返済する | 町が成長するにつれてプロジェクトが順次解放される |
| 2 | 役場で公共事業のリストを確認する | 夢見の館が提案プロジェクトとして現れる |
| 3 | 商店街の場所を選ぶ | 建物は町のマップではなく商店街に建設される |
| 4 | 時間をかけて234,000ベルを寄付する | ハニワに分割で寄付できる |
| 5 | 建設のために1日待つ | 館は翌日にオープンする |

実用的なヒント：早い段階から少しずつ資金を出すこと。通りかかるたびにハニワに数千ベルを入れる方が、234,000ベルを一度に貯めるよりもはるかに楽であり、毎日のルーティンを保つことができる。

## 町のアップロード：夢番地の仕組み

建物がオープンしたら、ゆめみに頼んであなたの町の夢を作ってもらおう。彼女はアップロードまたは更新ごとに5,000ベルを請求し、その後、夢番地 — 誰とでも共有できる12桁のコード — を渡してくれる。

そのコードがシステム全体の鍵だ。フォーラムに投稿したり、Discordサーバーに落としたり、友達のためにカードに書いたりしよう。それを入力した人は誰でも、アップロードした瞬間のあなたの町を訪問できる。後で道を並べ替えたり、新しい交配花を育てたりしても、ゆめみに更新料を払うまで夢は変わらない。

| 質問 | 自分の町をアップロードする | 夢を訪問する |
|---|---|---|
| 費用 | アップロードまたは更新ごとに5,000ベル | 無料 |
| 必要なもの | 誇れる、ほぼ完成した町 | 夢番地、またはランダムな夢 |
| 得られるもの | 共有可能な12桁の夢番地 | 他の誰かの町のツアー |
| 町へのリスク | なし | なし |
| 元に戻せる？ | はい — 変更後に再アップロードするだけ | 該当なし |

アップロードの過小評価されている利点の一つ：特定の瞬間のあなたの町の永久記録を作成できる。多くのプレイヤーは大規模な模様替えの前にアップロードし、後で古いレイアウトを再訪できるようにする。まるで自分の進歩のフォトアルバムのようだ。

## 夢の町の訪問：ルール

訪問は、ほとんどのプレイヤーが毎日使う夢見の館の半分だ。ゆめみは、特定の夢番地に送り出したり、町の名前で検索させたり、ただ閲覧したいだけならランダムな夢を選んだりできる。

体験は意図的に低リスクだ。到着し、探索し、帰る準備ができたら夢の中でゆめみに話しかけて目を覚ます。何も家に持ち帰ることはない — だからこそこの機能はとてもリラックスできるのだ。

| できること | できないこと |
|---|---|
| 町全体を歩き、レイアウトを研究する | アイテム、花、果物を持ち帰る |
| 町の住民と話す | 町の何かを永久に変更する |
| 家をツアーし、インテリアデザインを鑑賞する | 取引、買い物、ビジネスを行う |
| 掲示板を読み、デザインのアイデアを得る | 掘る、切る、その他町を損傷する |
| 他の地域や言語の町を訪問する | 景観を変える道具を持ち込む |

リスクがゼロなので、夢は高度な造園を研究する最も安全な方法だ。完璧な果樹園のグリッドが実際にどう見えるか、あるいはテーマのあるカフェ地区がどう流れているかを見たい？一晩で12の夢の町を訪問してメモを取ろう。
